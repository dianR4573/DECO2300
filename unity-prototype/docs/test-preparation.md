# Test Preparation — Interactive Prototype 1

## Project name

**Notion AR: Turning 2D Notes into 3D Spatial Ideas**

## Three-sentence pitch

This project redesigns Notion as a mixed-reality workspace for visual note-taking and early design thinking. Users place a Notion page on a table, create a 2D sketch, and use a simulated lifting interaction to turn it into a 3D object. The Unity prototype tests whether this XR interaction is understandable, useful, and worth developing further.

## Testing objective

From the concept, the main untested assumption is whether users will understand and value the process of turning a 2D Notion sketch into a 3D spatial object.

This test aims to discover whether the workspace, document placement, 2D-to-3D transformation, and object movement are clear enough for users to understand the intended XR experience.

## Testing methodology

The test uses a short task-based usability walkthrough with observation notes, task success/failure, rating questions, and short interview questions. Each participant will complete the same interaction sequence in the Unity prototype so results can be compared across users.

## Prototype description / requirements

The prototype is designed to simulate a low-level experience of Notion AR. It includes a simple Unity 3D table environment, a floating document picker, a Notion-style page, a 2D sketch, a simulated lifting transformation into a 3D object, and basic object movement.

## Data collection method

During the testing process, I will:

- Observe where the participant hesitates or becomes confused.
- Record whether each task is completed successfully.
- Ask participants to rate ease of use and usefulness.
- Log results in a simple table for later evaluation and iteration.

## Testing setup

Before each test:

1. Open the Unity prototype.
2. Reset to the start state.
3. Make sure controls are visible.
4. Tell the participant this is a concept prototype, not a finished product.
5. Explain that they should think aloud if something feels off.

Needed materials:

- Laptop/computer running the Unity prototype.
- Keyboard and mouse.
- Results table or notes document.
- Timer.

## Evaluation focus

The prototype will be considered successful if participants can:

- Understand that the page is a workspace.
- Understand the 2D sketch becomes a 3D object.
- Explain why the 3D transformation might be useful.
- Complete the main interaction flow without major help.
