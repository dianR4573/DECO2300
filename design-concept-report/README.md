# DECO2300 Design Concept Report — Notion AR

This folder documents the DECO2300 Design Concept Report work for **Notion AR: Turning 2D Notes into 3D Spatial Ideas**.

## Folder contents

- [`report/`](report/) — final A4 report document, AI acknowledgement PDF, and text extract for readability.
- [`prototype-photos/`](prototype-photos/) — low fidelity prototype photos used in the report.
- [`storyboard/`](storyboard/) — storyboard showing how the idea evolved from a wrap around whiteboard into a surfaced based Notion AR workspace.
- [`process-notes/`](process-notes/) — short notes on concept evolution and initial testing plan.

## Design process evidence
The concept evolved from a broad AR whiteboard idea into a more focused table Notion workspace. The final concept uses XR affordances such as surface detection, hand tracking, L-shaped document selection, two-hand lifting from 2D to 3D, and pinch movement.
