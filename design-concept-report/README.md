# DECO2300 Design Concept Report — Notion AR

This folder documents the DECO2300 Design Concept Report work for **Notion AR: Turning 2D Notes into 3D Spatial Ideas**.

## Concept summary
The concept redesigns Notion as a Meta Quest 3 mixed-reality workspace. A user can open a Notion document list with an L-shaped hand gesture, place a note onto a real table, draw simple 2D shapes/designs, raise the drawing into a 3D representation, and move the object with pinch interaction.

## Folder contents

- [`report/`](report/) — final A4 report document and text extract for readability.
- [`prototype-photos/`](prototype-photos/) — low-fidelity prototype photos used in the report.
- [`storyboard/`](storyboard/) — storyboard showing how the idea evolved from a wrap-around whiteboard into a table-based Notion AR workspace.
- [`process-notes/`](process-notes/) — short notes on concept evolution and initial testing plan.
- [`assignment-brief/`](assignment-brief/) — task sheet and AI acknowledgement template used as assignment references.

## Design process evidence
The concept evolved from a broad AR whiteboard idea into a more focused table-based Notion workspace. The final concept uses XR affordances such as surface detection, hand tracking, L-shaped document selection, two-hand lifting from 2D to 3D, and pinch movement.
