# Initial testing plan

Participants would complete one short scenario:

1. Make the L-shaped hand gesture to open a list of Notion documents.
2. Select a Notion page and place it onto a table.
3. Draw a simple 2D shape/design.
4. Raise the 2D sketch into a 3D object using a two-hand lifting gesture.
5. Move the 3D object with a pinch interaction.

## What to test
- Whether the 2D-to-3D transformation feels useful.
- Whether the table-based workspace makes the interaction easier to understand.
- Whether the L-shaped document-selection gesture is discoverable.
- Whether users can move the object comfortably with pinch interaction.

## Data to collect
- Task success/failure.
- Observation notes and hesitation points.
- Participant comments.
- Ease-of-use rating.
- Usefulness rating.
